# UZ801

本页记录 **UZ801 v3** MSM8916 modem 棒的 OpenWrt 配置与硬件验证情况。它是
旧有的 "UZ801" 产品线；设备树采用原厂 `msm8916-yiming-uz801v3.dts`，仅对
LED 重新布线（补丁 803）。

## 构建标识与存储

- 构建别名：`uz801`
- OpenWrt 设备配置：`yiming-uz801v3`
- DTS：`msm8916-yiming-uz801v3`
- eMMC：7,569,408 扇区 × 512 字节（4 GB 级别）
- GPT 总扇区数：7,569,408
- 恢复分区：**无**（15 分区布局）

## LED

| GPIO | 功能 | 说明 |
| ---: | :------- | :--- |
| 6 | `wlan`（蓝色） | Wi-Fi AP 活动 |
| 7 | `power`（红色） | modem / 电源状态（以 `red:power` 暴露） |
| 8 | `wan`（绿色） | 4G / 互联网活动 |

UZ801 v3 **确实**在 **GPIO7** 上有一颗红色 LED（见补丁 803，以
`red:power` 暴露）；此前"没有红色 LED"的说法是错的。与其他棒相比，其
WLAN/WAN 颜色分配是相反的（WLAN = 蓝色，WAN = 绿色）。

## Reset / failsafe 按键

- GPIO **23**，**低电平有效，上拉**（空闲为高——与 UF02/HMUF02-V5 *相反*
  的极性）。这曾是一个早期 bug 的根源：短按被读成"一直被按住"并触发了
  恢复出厂设置；已改回低电平有效/上拉以匹配硬件。
- **Failsafe 流程在 UZ801 上尚不可用**——按键的空闲电平和响应已验证，但
  **不要**依赖它进行恢复。请使用串口 `f` 键。在系统运行中长按 5 秒仍会
  执行恢复出厂设置。
- 参见 [Failsafe](../Failsafe/README.md)。

## SIM

UZ801 配置中未暴露 `sim-presence` / `sim_hotplug` 节点，因此物理 SIM 热
插拔**未测试**。参见 [SIM Hot-Swap](../SIM_HOT_SWAP.md)。

## 配置功能选择

遵循公共基线：

- Bluetooth —— **软件存在，但 UZ801 v3 没有 Bluetooth 天线**，因此该板上
  Bluetooth 不可用
- WPA3-SAE 与多 SSID
- CPU CPR 与 800 MHz 上限
- **A2 电源轨保持**（补丁 851）—— 与 HMUF02-V5 同属 HiMI 基带系列

不包含：HMUF02-V5 热量映射、`qcom-time-daemon`、恢复分区，以及（事实上）
Bluetooth。

## 备注

"UZ801" 这个名字也是 RF 移植供体产品线的旧账本文件名；**受测设备是
HMU05/HMUF02-V5**，不是 UZ801。参见 wiki 中的
[Modem Stability](../Modem%20Stability/README.md)。
