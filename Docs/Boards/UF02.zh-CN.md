# UF02

本页记录 **UF02** MSM8916 modem 棒的 OpenWrt 配置与硬件验证情况。它与
HMUF02-V5 共用同一基带产品线（同款 HiMI modem），因此继承了 A2 电源轨保持，
其余部分则遵循公共板卡基线。

## 构建标识与存储

- 构建别名：`uf02`
- OpenWrt 设备配置：`generic-uf02`
- DTS：`msm8916-generic-uf02`（型号 `UF02 4G Modem Stick`）
- `SUPPORTED_DEVICES`：`uf02,250605v0s`
- eMMC：7,569,408 扇区 × 512 字节（4 GB 级别）
- GPT 总扇区数：7,569,408
- 恢复分区：**无**（15 分区布局）

## LED

| GPIO | 功能 | 说明 |
| ---: | :------- | :--- |
| 72 | `wan`（绿色） | 4G / 互联网活动 |
| 73 | `wlan`（蓝色） | Wi-Fi AP 活动 |

## Reset / failsafe 按键

- GPIO **23**，**高电平有效，下拉**（空闲为低，按下为高）。
- 开机后前 7 秒内短按进入 **failsafe**；系统运行中长按 5 秒执行
  **恢复出厂设置**。
- 真机验证？**尚未**——声明为高电平有效/下拉，但按键流程未确认。如果它
  毫无反应，请使用串口 `f` 键。
- 参见 [Failsafe](../Failsafe/README.md)。

## SIM

UF02 板级补丁**未**暴露 `sim-presence` / `sim_hotplug` 节点，因此该板的
物理 SIM 热插拔**未测试**。SIM 在启动时选定；如何在你的设备上验证该线路，
参见 [SIM Hot-Swap](../SIM_HOT_SWAP.md)。

## 配置功能选择

遵循公共基线：

- failsafe（按键，未验证）
- Bluetooth
- WPA3-SAE 与多 SSID
- CPU CPR 与 800 MHz 上限
- **A2 电源轨保持**（补丁 851）—— 与 HMUF02-V5 相同的 HiMI
  `HIMI_U01_MODEM_V1.0` modem，同样暴露给 `a2_power.c:1189` 静默卡死问题

不包含：

- `qcom-time-daemon`（仅限 HMUF02-V5）
- 恢复分区

## 备注

MSM8916 系列的 modem 固件与原厂 Android 完全相同；约 900 秒的 modem 致命
故障在 AP 侧，由 A2 保持 + Himi-OK 门控缓解。参见 wiki 中的
[Modem Stability](../Modem%20Stability/README.md)。
